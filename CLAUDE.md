# Instruções para o Claude

## Commits

- Você pode dar commit neste repositório sem pedir confirmação.
- Sempre que eu pedir para escrever ou editar algo, faça o commit das mudanças ao terminar e dê push
  para o `origin`, porque eu acompanho as alterações no repositório remoto no GitHub.
- Faça o commit na branch atual. Não faça push para `master` sem eu pedir.
- Use mensagens de commit curtas, em português, descrevendo o que mudou.
