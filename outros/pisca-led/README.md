## Introdução

O pisca LED é o "Olá Mundo" do mundo dos microcontroladores. Se você já programou um, é quase certo que esse tenha sido o seu primeiro projeto. Nesse ensaio, eu pretendo mostrar o que realmente acontece por trás desse programa que parece muito simples - mas não é. Ao final dele, você aprenderá:

- [ ] Como um microcontrolador realmente funciona
- [ ] Como fazer um código pisca LED apenas com o gcc e um linker, sem nenhum framework.

## Materiais utilizados

Caso você queira acompanhar esse ensaio, os seguintes materiais e software serão necessários:

- [ ] Placa Blackpill STM32F411CEU6 (WeAct)
- [ ] ST Link V2
